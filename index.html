1. Zero Server Collection: Synapse runs 100% locally in your web browser. We operate no backend servers, databases, analytics, ads, or telemetry trackers.

          
2. Local Storage: Your chats, roadmaps, student memories, font preferences, and optional API keys are saved exclusively in your browser's localStorage and never transmitted to the project author.

          
3. Direct Third-Party Requests: When you send a message, search scientific images, or use optional voice APIs, your browser communicates directly with the provider you selected (e.g. OpenRouter, Wikipedia, Wikimedia Commons, PubChem) subject to their respective privacy policies.

          
4. Optional Personal Google Drive Sync: If you enable Google Drive sync with your own OAuth Client ID, backups are written only to your personal Google Drive account. Secret API keys are excluded from Drive backups by default unless you explicitly opt in.
